# realTasia public record

This repository supplies the public organisation profile and publication record for [realTasia](https://github.com/realtasia).

It contains:

- [the organisation profile](https://github.com/realtasia);
- [the archive and editorial policy](./ARCHIVE_POLICY.md);
- [the archive log](./ARCHIVE_LOG.md);
- historical identity assets and modern display derivatives.

The six source repositories are preserved separately as private archival masters. Their contents are not publicly accessible through this organisation.
